 • Sistema del proyecto
 • El sistema consiste en dos ambientes de aula que se instrumentarán para hacer mediciones y detecciones de lo que esté ocurriendo (o no ocurriendo) en el ambiente. (L-419, A-1001 libre 18 pm jueves)
