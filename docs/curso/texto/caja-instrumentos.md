Sugerencias para el desarrollo de las cajas de los sensores y procesador
Se necesita diseñar cajas que contendrán cada sensor y el procesador. Estas cajas son sistemas propiamente y deben ser desarrollados de acuerdo a los procesos aprendidos y utilizando las herramientas apropiadas.
Cada caja deberá contener el sensor, baterías, y una unidad (procesador ESP32) que permita al sensor convertirse en un IoT inalámbrico.
Poner atención a lo siguiente
 • Debe haber una apertura adecuada al sensor para que pueda realizar la medición.
 • Debe haber una manera de manejar la energía
 • De preferencia baterías que se recargan con luz ambiental
 • Prendido y apagado del sistema sensor.
 • El diseño de la caja se presentará para ser construido por impresión 3D
 • Cada grupo entregará un diseño de caja para cada sensor y el procesador, y el docente elegirá los diseños que se van a imprimir.
